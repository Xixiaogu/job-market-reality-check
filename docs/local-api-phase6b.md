# Phase 6B：浏览器扩展直连本地 API

## 用户流程

1. 启动 `run_local_api.ps1`。
2. 打开扩展，把 `local_api/runtime/api_token.txt` 的内容粘贴到令牌框。
3. 点击“保存并测试”完成一次性配对。
4. 浏览 BOSS 岗位详情页，点击“采集并同步岗位”。
5. 岗位同时保存到浏览器备份与 SQLite。
6. 新增或更新岗位时，扩展自动启动分析管线。
7. 点击“打开看板”查看最新结果。

## 安全边界

- API 只监听 `127.0.0.1`。
- 写入、查询和任务状态接口要求 `X-Job-Market-Token`。
- 令牌保存在 `chrome.storage.local`，不写入扩展源代码和 Git。
- 健康检查和看板页面保持只读、无需令牌。
- JSONL/CSV 导出仍作为离线备份保留。

## 去重与分析策略

- SQLite 继续按 `job_id` upsert。
- 未变化岗位不会重复启动分析。
- 只有新增或更新时，且“同步后自动更新分析看板”已勾选，才会触发管线。
- 已有分析任务运行时，后端返回现有任务，不会并发重复执行。
