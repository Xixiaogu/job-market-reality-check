# Phase 8.2C：投递决策中心

## 目标

把 Phase 8.2B 的可解释评分结果转化为可操作的本地页面。页面默认只展示待投递队列，并按“立即投递、值得冲刺、补材料后投递、暂缓”组织岗位。

## 页面

- `/decision`：投递决策中心
- `/profile`：个人档案
- `/manage`：岗位管理
- `/calibrate`：人工校准

## 主要能力

1. 保守、平衡、冲刺三种投递策略切换。
2. 投递优先级、岗位匹配度、机会价值三项核心分数。
3. 推荐理由、技能缺口、硬条件冲突、信息风险和项目证据解释。
4. 默认移除已投递、笔试、面试、Offer、被拒、放弃和已关闭岗位。
5. 可切换“显示全部岗位”查看历史状态。
6. 在详情抽屉中直接修改求职状态，复用 Phase 7B 管理 API。
7. 展示人工校准的一致率、Top 5 重合度和硬条件漏判数。

## 边界

本页面展示的是透明规则形成的投递决策建议，不是 Offer 概率预测，也不替代用户核实岗位真实性和实际招聘状态。
