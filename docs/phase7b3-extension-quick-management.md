# Phase 7B.3：浏览器扩展快捷求职管理

## 产品边界

扩展继续负责靠近岗位页面的轻量操作：

- 采集或更新当前岗位；
- 选择个人求职进度；
- 添加简短个人备注；
- 单独保存已有岗位的状态；
- 打开完整岗位管理中心。

招聘状态、分析口径、人工分类、归档、历史记录和批量操作继续放在 `/manage` 页面，不塞进扩展弹窗。

## 使用流程

### 新岗位

1. 打开 BOSS 岗位详情页。
2. 在扩展中选择求职进度并填写备注。
3. 点击“采集并同步岗位”。
4. 扩展先 upsert 岗位，再写入 `job_management`。
5. 到 `/manage` 可以看到状态和备注。

### 已采集岗位

1. 打开原岗位页面和扩展。
2. 扩展自动从 SQLite 读取当前求职状态。
3. 修改状态或备注。
4. 点击“保存求职状态”，无需重新采集岗位。

## 状态选项

- 待判断
- 感兴趣
- 准备投递
- 已投递
- 笔试
- 面试
- Offer
- 被拒
- 放弃

## 分析触发规则

个人状态和备注不影响市场统计，因此单独保存时不会启动分析管线。

岗位采集本身新增或更新时，仍沿用 Phase 6B 的自动分析规则。
