# Phase 8.1C：首次使用与冷启动体验

## 目标

让没有历史档案、没有岗位样本的新用户，也能从第一个真实岗位开始使用系统，而不是先填写一张完整表格。

## 数据来源

- 用户确认：学历、毕业年份、求职类型、城市和能力等级。
- 岗位语料：已采集岗位中的技能与岗位方向。
- 冷启动建议：样本不足时，根据用户选择的方向提供起始候选；不代表用户已经掌握。
- 项目证据：由项目与技能关联生成，首次使用时可跳过。

## 样本成熟度

- 0 个岗位：冷启动，仅提供方向起始建议。
- 1—2 个岗位：第一批真实岗位候选。
- 3—9 个岗位：初步画像。
- 10 个及以上岗位：样本较稳定。

## 首次使用路径

1. 启动本地 API 并配对插件。
2. 在 BOSS 岗位详情页打开插件。
3. 点击“采集为第一个样本”。
4. 打开个人档案，完成 60 秒核心设置。
5. 确认来自真实岗位或目标方向的技能建议。
6. 项目与高级条件以后按需补充。
