# 市场分析看板统一外壳整合（开发验证版）

## 目标

在稳定标签 `desktop-v1.0.2` 的基础上，将 `/dashboard` 并入统一桌面外壳：

- 最左侧继续显示应用一级导航；
- 一级导航右侧显示市场分析二级导航；
- 原看板内容位于右侧内容区；
- 删除旧的浮动“岗位管理中心”入口；
- 保留看板现有图表、筛选、折叠、放大和实时状态逻辑；
- 不修改数据库、分析算法和统计口径。

## 页面结构

```text
统一一级导航
├─ 投递决策
├─ 岗位管理
├─ 分析看板（当前）
├─ 个人档案
├─ 人工校准
└─ 扩展与设置

市场分析二级导航
├─ 样本概览
├─ 技能需求
├─ 岗位方向
├─ 实习约束
├─ 薪资与公司
└─ 岗位明细
```

## 实现方式

`local_api/app_shell.py` 在 `/dashboard` 页面加载完成后，将看板原有
`#ux-sidebar` 移入 `#jm-app-main` 内部的双栏布局。市场分析看板仍由现有
`dashboard_ux_v12.py` 生成，因此图表和交互逻辑不需要重写。

`dashboard_management_link_v13.py` 保留兼容调用，但只清除旧浮动链接，
不再生成第二套应用级导航入口。

## 手动验收

1. 完全退出旧桌面程序。
2. 启动新开发版 EXE。
3. 打开“分析看板”。
4. 确认最左侧一级导航仍然可见。
5. 确认其右侧出现“市场分析”二级导航。
6. 点击二级导航各项，页面应滚动到对应分析区。
7. 页面右上角不再出现“岗位管理中心”。
8. 一级导航可正常进入投递决策、岗位管理、个人档案和人工校准。
9. 折叠一级导航后，市场分析内容仍保持正常。
10. 图表放大、章节折叠、岗位筛选和实时状态仍正常。
