# 桌面 v1.0.7 基线冻结

状态：`frozen-for-skill-v1`  
生效日期：`2026-07-29`

## 冻结范围

以下桌面能力在 Skill v1 开发期间冻结：

- 岗位 SQLite 数据模型与岗位管理状态；
- 个人档案、项目证据和人工校准模型；
- 决策评分维度、权重、阈值和四档行动分组；
- 岗位管理、市场分析、个人档案、决策中心和设置页的主要信息架构；
- 浏览器扩展到本地 API 的采集协议；
- v1.0.7 的标准浅色和 Windows Acrylic 行为。

冻结意味着不继续添加 UI 页面、不调整评分规则、不以 Skill 开发为由复制业务逻辑。

## 允许修改

只有以下修改可以进入桌面基线：

- 阻塞 Skill 读取稳定事实的 API 缺陷；
- 数据损坏、隐私泄露或 Token 安全问题；
- 安装、启动、卸载、迁移、备份和发布验收缺陷；
- 能被自动测试复现的明确回归；
- 文档、测试、类型、日志和不改变业务结果的内部整理；
- 为保持只读 API 向后兼容所需的补丁。

## 需要延后的修改

- 新视觉主题和非必要布局调整；
- 新评分维度、权重优化和阈值调参；
- 自动投递、自动沟通和批量 Agent 写操作；
- 简历生成、面试辅导和 PDF 报告等 Skill v1 以外模块；
- 商业级自动升级、签名和遥测系统。

## 基线验收门

基线只有同时满足以下条件才视为关闭：

1. `main` 对应的发布提交工作区干净；
2. v1.0.7 ZIP SHA256 与发布文件一致；
3. v1.0.7 打包 EXE smoke test 通过；
4. v1.0.7 安装、启动检查、卸载和用户数据保留 smoke test 通过；
5. `scripts/test.ps1` 的契约、离线、API、桌面和 Skill 测试组全部通过；
6. 根 README 与当前产品一致；
7. `skill-v1-local-api-contract.md` 已冻结；
8. 未修改桌面评分权重、阈值或 UI 产品逻辑。

## Skill 分支规则

Skill 开发应从本基线建立分支，并遵守：

- 本地 API 是桌面事实的唯一来源；
- 第一阶段只读；
- 不直接访问 SQLite；
- 不修改桌面评分引擎；
- 每个判断包含岗位 ID、决策运行 ID、数据时间和证据来源；
- 需要桌面改动时，先证明它阻塞已冻结的 Skill 契约。
