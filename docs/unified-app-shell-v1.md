# 统一桌面应用外壳 V1

## 目标

在不重写现有页面和分析逻辑的前提下，把 FastAPI 页面统一成偏 macOS/iPadOS 的浅色玻璃质感桌面界面。

## 本阶段包含

- 固定左侧导航；
- 投递决策、岗位管理、分析看板、个人档案、人工校准和扩展设置统一入口；
- 当前页面高亮；
- 桌面宽屏自适应，减少左右无效空白；
- 侧栏折叠；
- 窄窗口抽屉导航；
- 同源内部链接留在当前 WebView；
- 外部岗位链接继续交给系统浏览器；
- 隐藏原页面顶部重复的全局导航按钮；
- 不修改数据库、评分算法或 API。

## 手动验收

1. 启动新版桌面 EXE。
2. 左侧显示统一导航，投递决策为当前高亮项。
3. 点击岗位管理、分析看板、个人档案，均在当前软件窗口中切换，不打开 Edge。
4. 点击真实招聘网站的原岗位链接，系统浏览器正常打开。
5. 页面顶部不再重复显示个人档案、岗位管理、分析看板三个全局按钮。
6. 重新计算、策略选择、保存档案等页面内操作仍正常。
7. 大屏下内容区占满侧栏以外的空间。
8. 点击侧栏底部折叠按钮，侧栏缩为图标模式；重启后折叠状态保留。
9. 窗口缩窄时出现左上角菜单按钮，侧栏以抽屉方式打开。
10. 浏览器直接访问同一地址时也能看到统一网页外壳，这是预期行为。

## 边界

本阶段只统一导航和视觉结构。页面内部卡片、表单和图表仍沿用现有组件，后续再逐页精修。
